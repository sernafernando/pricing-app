# Filtros de producto: las funciones de Productos en Publicaciones ML, Ventas ML y Métricas ML

Área: Publicaciones

## Resumen ejecutivo

Los filtros **Marca**, **Categoría**, **Subcategoría** y **PM** de Publicaciones ML, Ventas ML y Métricas ML ahora se manejan como en Productos: se tildan todas las subcategorías de una categoría de un clic, la búsqueda encuentra también por nombre de categoría y cada búsqueda se borra con ✕.

## Cómo se usa

1. Abrir **Marca**, **Categoría** o **Subcategoría**: el cursor queda en la búsqueda, listo para escribir. Al volver a la búsqueda se selecciona lo escrito, y **✕** la borra.
2. En **Subcategoría**, tildar el nombre de una categoría marca todas sus subcategorías a la vista; tildarlo de nuevo las desmarca. Si hay algunas marcadas, la casilla queda a medias y muestra cuántas (por ejemplo, 1/2).
3. Escribir el nombre de una categoría en la búsqueda de **Subcategoría** muestra todas sus subcategorías.
4. Cada subcategoría muestra su grupo de comisión (G1, G2…) y cada PM su email, cuando la pantalla los tiene.

## Para tener en cuenta

- Funciona igual en las tres pantallas: es el mismo filtro.
