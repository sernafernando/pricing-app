# Documentación de la API dentro del sistema

Área: Gestión

## Resumen ejecutivo

Quien desarrolla integraciones o revisa el sistema puede ver todos los endpoints de la API desde una página del sistema, también en producción, sin pedir acceso aparte.

- Necesita el permiso **Ver documentación de la API**. El rol Admin ya lo tiene; a otros usuarios se les da desde el panel de administración.
- La página muestra cada endpoint con sus parámetros y respuestas, y tiene un buscador.
- Desde la misma página se puede probar un endpoint: la llamada sale con la sesión de quien la hace y respeta sus permisos.

## Cómo se usa

1. Abrir **Gestión → API docs** en el menú lateral.
2. Buscar un endpoint con el buscador (o con **Ctrl+K**) o recorrer los grupos de la izquierda.
3. Para probarlo, abrir el endpoint y usar el botón **Test Request**.
