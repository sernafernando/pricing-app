# Sell out: anular varias campañas de una vez

Área: Productos

## Resumen ejecutivo

En la pestaña **Sell out** ya no hace falta entrar campaña por campaña para anularlas. Ahora se pueden seleccionar varias (o todas las de la búsqueda) y anularlas juntas, con una confirmación que dice cuántas se anulan. Es todo o nada: si alguna no se puede anular, no se anula ninguna.

## Cómo se usa

1. Abrir **Productos → Sell in / Sell out** y pasar a la pestaña **Sell out**.
2. Marcar la casilla de cada campaña, la casilla del encabezado para toda la página, o tocar **Seleccionar todo lo filtrado (N)** para todas las que coinciden con la búsqueda.
3. Tocar **Anular seleccionados**. La confirmación dice cuántas campañas se anulan y cuántas ya estaban anuladas (esas se omiten). Se puede escribir un motivo.
4. Tocar **Confirmar anulación**. El mensaje dice cuántas se anularon y cuántas se omitieron.

## Para tener en cuenta

- Pide permiso de gestión de campañas (sell_out.gestionar), igual que anular una sola.
- El sell out que acreditaron deja de contar: se borran sus consumos y se recalculan las ventas que alcanzaban.
- Si alguna no se puede anular, no se anula ninguna y el mensaje dice cuál y por qué.
- Si una campaña se está recalculando, el mensaje la nombra: esperar unos segundos y volver a intentar.
- Se pueden anular hasta 500 campañas por vez.
- Si al seleccionar todo lo filtrado aparece que la lista cambió, tocar **Actualizar** y volver a intentar.
