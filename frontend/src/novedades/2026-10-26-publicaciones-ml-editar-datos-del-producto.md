# Publicaciones ML: editar los datos del producto

Área: Publicaciones

## Resumen ejecutivo

En el panel de cada producto en **Publicaciones ML**, los **Datos del producto** copiados de una publicación ahora se pueden editar.

- Se pueden cambiar el título y la descripción.
- Las fotos se pueden quitar o reordenar. No se pueden subir fotos nuevas.
- Los atributos se pueden quitar, o se les puede cambiar el valor. No se pueden agregar atributos nuevos.
- Lo editado queda en el producto. La publicación de Mercado Libre no cambia.
- Si después se elige otra publicación con **Cambiar publicación**, se pierde lo editado.
- Solo pueden editar quienes tienen el permiso **Editar SKU y EAN del producto**.

## Cómo se usa

1. Abrir **Reportes → Publicaciones ML**, vista **Producto**, y tocar un producto.
2. En **Datos del producto**, tocar **Editar datos**.
3. Cambiar lo que haga falta:
   - Para ordenar las fotos, usar las flechas de cada una.
   - Para quitar una foto o un atributo, tocar la cruz.
4. Tocar **Guardar**.
