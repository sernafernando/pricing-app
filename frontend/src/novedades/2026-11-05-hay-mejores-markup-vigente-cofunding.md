# Hay mejores: el markup vigente contempla el aporte de ML

Área: Publicaciones ML

**Resumen ejecutivo:** si la publicación ya tiene aplicada una SMART, PRE_NEGOTIATED o PRICE_MATCHING al precio de venta, el aviso de “hay mejores” compara contra ese markup (con el aporte de Mercado Libre), no contra un cálculo que ignora la cofinanciación. Si no hay esa oferta aplicada, sigue usando el markup del sale sin aporte de ML.

## Cómo se usa

1. En **Publicaciones ML**, abrí una publicación con el filtro **Hay mejores ofertas**.
2. Mirá el markup vigente del bloque: debería coincidir con el de la promo aplicada cuando es cofinanciada.
3. Las candidatas SMART / DEAL / Premium solo aparecen si mejoran ese status quo.
