# Hay mejores ofertas: elegir candidatas al abrir

En Publicaciones ML, si una publicación está en el filtro **Hay mejores ofertas**, al abrirla el panel muestra el precio actual y las mejores candidatas **SMART** / **DEAL** / **Premium** (solo las que mejoran el precio vigente). El campo de nuevo precio aparece después de descartar la sugerencia o de aplicar una.

Una candidata “mejor” es: más markup al mismo precio, o precio más bajo con markup igual o mayor — nunca un precio de consumidor más alto, aunque el markup suba.
