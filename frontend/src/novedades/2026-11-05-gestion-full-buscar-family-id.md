# Gestión Full: buscar por family_id

Área: Reportes → Gestión Full

## Resumen ejecutivo

En **Planificación**, el buscador también encuentra filas por el **family_id** numérico de Mercado Libre (el agrupador de user products / familia).

## Cómo se usa

1. Abrí **Gestión Full** → **Planificación**.
2. Pegá el `family_id` completo en el buscador (solo el número exacto).
3. Van a aparecer las filas vinculadas a esa familia (Código ML / MLAU).

## Para tener en cuenta

- Tiene que ser el id completo; un fragmento no alcanza.
- Siguen funcionando EAN, descripción, Código ML e MLAU.
