# Publicaciones ML: vínculos cargados desde el sistema anterior

Área: Publicaciones

## Resumen ejecutivo

En **Publicaciones ML** se cargaron, una sola vez, los vínculos con productos que el sistema anterior ya tenía para publicaciones que el vínculo automático todavía no vinculaba. Son sobre todo publicaciones con SKU **"0"**.

- **Quedan como vínculos manuales:** el vínculo figura como **Manual** y se puede editar como cualquier otro.
- **Marcados como cargados del sistema anterior:** en el panel lateral, pestaña **Producto**, el campo **Nota** lo indica.
- **No pisa nada:** los vínculos manuales y automáticos que ya existían no se tocan. Si el vínculo automático ya encuentra el producto, se usa el automático.
- **Aclaración sobre el SKU:** si el SKU está vacío o solo tiene espacios, el vínculo automático usa el campo personalizado de la publicación en Mercado Libre. El SKU **"0"** nunca vincula. Por eso esas publicaciones necesitan esta carga o un vínculo manual.

## Cómo se usa

1. Abrir **Reportes → Publicaciones ML** y hacer clic en una publicación para abrir el panel lateral.
2. Entrar a la pestaña **Producto**.
3. Revisar el vínculo y, si el producto no es el correcto, cambiarlo como cualquier vínculo manual.

> Para que una publicación se vincule sola en el futuro, cargar en Mercado Libre un SKU que sea el código del producto o su ID.
