# Publicaciones ML: rebate y web transferencia editables en la fila

Área: Publicaciones

## Resumen ejecutivo

En Publicaciones ML, las celdas **Precio Rebate** y **Web Transf.** ahora se editan desde la misma fila, igual que en Productos. Se puede activar o desactivar cada una y cambiar su porcentaje. En web transferencia también se puede marcar si el porcentaje se conserva en los cambios masivos.

## Cómo se usa

1. Abrir **Reportes → Publicaciones ML** con los precios en modo **Normal**.
2. Hacer clic en la celda **Precio Rebate** o **Web Transf.** de una publicación con producto vinculado.
3. Marcar o desmarcar **Participa** y escribir el porcentaje: el % de rebate, o el % sobre la clásica para web transferencia.
4. En web transferencia, marcar **Conservar el % en cambios masivos** para que los cambios masivos no lo modifiquen.
5. Hacer clic en **Guardar** o presionar **Enter**. **Cancelar** o **Escape** cierran sin guardar.

## Para tener en cuenta

- Se guarda igual que en Productos y en el panel del producto. El rebate acepta porcentajes de 0 a 100. Un producto que nunca tuvo rebate arranca en 3,8 % y uno sin web transferencia arranca en 6 %.
- La celda de rebate requiere el permiso para cambiar el rebate, y la de web transferencia, el permiso para cambiar web transferencia.
- Después de guardar, la lista se vuelve a cargar con los precios nuevos.
