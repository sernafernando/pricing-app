# RMA Seguimiento: pestaña "Para borrar"

Área: Soporte

## Resumen ejecutivo

En **RMA Seguimiento** hay una pestaña nueva, **Para borrar**, que lista los casos que tienen tildado **Marcado para borrar pedido**. Cada caso tiene un tilde **Revisado**: al tildarlo queda guardado quién y cuándo lo revisó, y el caso deja de aparecer en la lista de pendientes. Arriba hay un filtro claro con **Pendientes**, **Revisados** y **Todos**, cada uno con su cantidad.

## Cómo se usa

1. Abrir **Soporte → RMA Seguimiento**.
2. Tocar la pestaña **Para borrar**. Abre en **Pendientes**: los casos marcados para borrar que nadie revisó todavía.
3. Revisar el pedido y tildar **Revisado** en su fila. El caso sale de **Pendientes** y pasa a **Revisados**, con el nombre de quien lo revisó y la fecha.
4. Para ver los ya revisados, tocar **Revisados**; para ver todos, **Todos**. Si un caso se tildó por error, destildarlo lo devuelve a **Pendientes**.

El tilde **Revisado** aparece solo para quien tiene permiso para gestionar RMA. El resto ve la lista y quién revisó cada caso, sin poder cambiarlo.
