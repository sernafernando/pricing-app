# Admin: ordenar la lista de usuarios

Área: Administración

## Resumen ejecutivo

En **Gestión → Admin → Usuarios**, la lista de usuarios ahora se puede ordenar con **Ordenar por**, debajo del buscador.

- **ID (creación):** el orden en que se crearon los usuarios. Es el orden por defecto.
- **Nombre** y **Usuario:** alfabético, sin importar mayúsculas ni acentos.
- **Rol:** agrupa los usuarios por rol y, dentro de cada rol, por nombre.
- **Estado:** primero los activos y después los inactivos, cada grupo por nombre.
- **El botón ↑ / ↓** al lado invierte el orden (ascendente o descendente) y se mantiene al cambiar de criterio.
- **La búsqueda sigue funcionando:** los resultados se muestran en el orden elegido.

## Cómo se usa

1. Abrir **Gestión → Admin → Usuarios**.
2. Elegir un criterio en **Ordenar por**.
3. Tocar **↑** para pasar a descendente (o **↓** para volver a ascendente).
