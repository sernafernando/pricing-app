# Sell out: programas para agrupar campañas

Área: Productos

## Resumen ejecutivo

Las campañas de sell out que son el mismo acuerdo (las que se renuevan cada trimestre o las que se llaman igual con un número porque aplican a cosas distintas) ahora se agrupan en **programas**. La pestaña **Sell out** las muestra agrupadas por programa, se filtran por programa y se asignan en bloque. Asignar un programa no cambia la plata de las campañas: solo las agrupa.

## Cómo se usa

1. Abrir **Productos → Sell in / Sell out** y pasar a la pestaña **Sell out**.
2. Si aparece el aviso «N sugerencias de programa: campañas sin programa con las mismas fechas», tocar **Ver sugerencias**: cada tarjeta propone un nombre (editable) para campañas sin programa con las mismas fechas. **Crear programa y asignar** las agrupa; **Descartar** oculta la tarjeta.
3. Para asignar a mano: marcar campañas (o **Seleccionar todo lo filtrado**), tocar **Asignar a programa** y elegir un programa existente o crear uno nuevo.
4. Con **Ver: Por programa | Lista** se cambia entre la vista agrupada y la lista de siempre. En **Por programa**, tocar un programa muestra sus campañas.
5. El filtro **Programa** muestra las campañas de un programa o las que no tienen.

## Para tener en cuenta

- Asignar un programa no cambia lo que acreditan las campañas ni la ganancia.
- Las sugerencias solo agrupan campañas sin programa con exactamente las mismas fechas, y no se aplican hasta confirmarlas. Descartar no se guarda: vuelven a aparecer al abrir la página otra vez.
- Un programa archivado no recibe campañas nuevas.
- **Renovar** deja la copia en el mismo programa mientras esté activo.
- Asignar y las sugerencias son solo para quien gestiona campañas.
