# Publicaciones ML: ancho del panel ajustable

Área: Reportes

## Resumen ejecutivo

En **Publicaciones ML** ahora se puede cambiar el ancho del panel de detalle. Arrastrando la línea entre la tabla y el panel, la tabla se achica y el panel muestra más, por ejemplo para ver mejor los precios. El ancho elegido queda guardado en el navegador.

## Cómo se usa

1. Abrir **Reportes → Publicaciones ML** y hacer clic en una publicación o en un producto para abrir el panel.
2. Pasar el mouse por la línea fina entre la tabla y el panel: el cursor cambia a flechas a los costados.
3. Arrastrar hacia la izquierda para agrandar el panel, o hacia la derecha para agrandar la tabla.
4. Con el teclado: llevar el foco a la línea con **Tab** y usar las flechas **←** y **→**.

## Para tener en cuenta

- Ni la tabla ni el panel se pueden achicar por debajo de un ancho mínimo, para que los dos sigan siendo legibles. En una ventana muy angosta, donde no entran los dos mínimos, el panel conserva el suyo y la tabla queda más chica.
- Hasta que se arrastre por primera vez, el panel tiene el mismo ancho que antes.
- El ancho queda guardado por navegador: en otra computadora o en otro navegador el panel arranca con el ancho de siempre.
