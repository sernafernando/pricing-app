# Productos: el color de un producto se guarda en la capa de equipo elegida

Área: Productos

## Resumen ejecutivo

En **Productos**, pintar un solo producto (desde el selector de color de la fila o con las teclas 0 a 7) con una capa de equipo activa guardaba el color en la capa **Global**. La fila se veía pintada hasta recargar, pero el color quedaba en la otra capa.

Ahora el color se guarda en la capa activa. Pintar varios productos a la vez ya funcionaba bien.

## Cómo se usa

1. Abrir **Productos** y elegir una capa de equipo.
2. Pintar un producto. Al recargar, el color sigue en esa capa.

Los colores que se pintaron así antes de este cambio quedaron en la capa Global. Si hace falta, se vuelven a pintar en la capa del equipo.
