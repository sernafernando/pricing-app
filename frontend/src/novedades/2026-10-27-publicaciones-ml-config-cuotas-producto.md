# Publicaciones ML: configuración de cuotas de cada producto

Área: Publicaciones

## Resumen ejecutivo

En la pestaña **Precios** del panel de cada producto en **Publicaciones ML**, debajo de los precios, aparece la **configuración de cuotas** del producto. Es la misma que se edita con el engranaje en **Productos**.

- **Recalcular cuotas**: si las cuotas del producto se recalculan cuando cambia el precio. Las opciones son usar la configuración global, siempre o nunca.
- **Markup adicional de cuotas Web y PVP**: el markup extra que llevan las cuotas de ese producto. Si queda vacío, se usa el global. El markup de cuotas PVP ahora se puede cambiar desde Publicaciones ML.
- La editan quienes tienen el permiso de editar precios de cuotas. Guardar no cambia ningún precio: la configuración se aplica la próxima vez que se recalculen las cuotas.

## Cómo se usa

1. Abrir **Reportes → Publicaciones ML**, elegir la vista **Producto** y tocar un producto.
2. Ir a la pestaña **Precios** y bajar hasta **Configuración de cuotas**.
3. Tocar **Editar cuotas**, cambiar lo necesario y tocar **Guardar**.
