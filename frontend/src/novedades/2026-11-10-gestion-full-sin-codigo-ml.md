# Gestión Full: MLAUs sin Código ML

Planificación también muestra familias **sin Código ML** (nunca entraron a Full). En **Fuera de Full** / **Todos** podés override, marcar Listo y exportar: el Excel oficial deja vacía la columna Código ML y completa SKU, MLA y cantidad con lo que haya. Seller Center puede pedir el código después.
