# Publicaciones ML: competencia de catálogo en la fila del producto

Área: Publicaciones

## Resumen ejecutivo

En la vista **Producto** de Publicaciones ML, la fila de cada producto con publicación de catálogo ahora muestra junto al nombre el mismo indicador de competencia que Productos.

## Cómo se usa

1. Abrir **Reportes → Publicaciones ML** y elegir la vista **Producto**.
2. Junto al nombre del producto se ve el indicador de catálogo:
   - Un trofeo: está ganando el catálogo.
   - Un apretón de manos: comparte el primer lugar.
   - Un signo de alerta: está compitiendo sin ganar.
3. Pasar el mouse sobre el indicador para ver el precio con el que gana o empata, o el precio necesario para ganar.

## Para tener en cuenta

- El estado es el mismo que calcula Productos para el producto.
- Los productos sin publicación de catálogo no muestran el indicador.
