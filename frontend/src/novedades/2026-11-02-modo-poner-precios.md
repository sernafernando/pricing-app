# Publicaciones ML: MODO PONER PRECIOS

Área: Publicaciones

## Resumen ejecutivo

En **Publicaciones ML** hay un flujo paralelo para cargar precios más rápido.

Qué tenés que saber:

- **MODO PONER PRECIOS** (si podés editar precios y activar promos) oculta KPIs, fuerza la vista Publicaciones y deja un set fijo de columnas.
- Bajo **Precio** ves la lista ERP (Clásica / cuotas / PVP), no el tipo de listado de Mercado Libre.
- El panel lateral, en este modo, abre sin pestañas: lista, precio actual y campo de nuevo precio.
- Con **Enter** guardás el precio en Pricing y elegís una sola promo entre la mejor SMART, la mejor DEAL y la Premium del mes.
