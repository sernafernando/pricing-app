# Editar y borrar aportes de marcas en campañas de Ads ML

Área: Métricas ML

## Resumen ejecutivo

En **Reportes → Aportes de marcas (Ads ML)** ahora se puede corregir un aporte ya cargado o borrarlo si fue un error o ya no corresponde. Métricas ML refleja el cambio: al borrar un aporte, vuelve a descontar del Total Gauss el costo que ese aporte cubría.

- **Editar:** el lápiz al lado de cada aporte abre el formulario con los datos cargados (tipo, valor, fechas, cómo se liquida el monto fijo, marca y nota).
- **Borrar:** el tacho al lado de cada aporte pide confirmar antes de borrar; nada se borra con un solo clic.
- **Permisos:** editar y borrar requieren el permiso **Gestionar aportes de marcas a campañas de Ads** (por defecto, solo administradores).

## Cómo se usa

1. Abrir **Reportes → Aportes de marcas (Ads ML)**.
2. Para corregir un aporte, tocar el lápiz, cambiar los datos y tocar **Guardar aporte**.
3. Para quitar un aporte, tocar el tacho y confirmar con **Borrar** (o **Cancelar** para dejarlo como estaba).

> Si al editar el rango se superpone con otro aporte de la misma campaña, el sistema no lo guarda y muestra el motivo en el formulario.
