# Envío Gratis

Área: Gestión
Ruta: Gestión → Envío Gratis
Permiso: Pedile a un administrador el permiso para ver las alertas de envío gratis (alertas.ver_free_shipping).

## Para qué sirve

Muestra las publicaciones que tienen envío gratis activado pero cuyo precio rebate es menor a $33.000 (lo que genera un error). Permite desactivar el envío gratis manualmente.

## Cómo se usa

Arriba dice **Alertas de Envío Gratis**. Se listan las publicaciones con error de envío gratis, con su MLA, título, precios, logística y estado de auto-fix.

El botón **Actualizar** recarga la lista. Para cada publicación hay un botón **Sacar envío** (título "Sacar envío gratis manualmente") que desactiva el envío gratis y muestra el progreso (cargando/éxito/fallo).

## Filtros y columnas

Sin filtros. Columnas: MLA, Título, Precio Publicado, Precio Rebate, Logística, Auto-Fix y Acciones.

## Botones y acciones

- **Actualizar**: recarga la lista.
- **Sacar envío**: desactiva el envío gratis en MercadoLibre para esa publicación.

## Preguntas frecuentes

**¿Qué causa el error de envío gratis?**
Envío gratis activado pero precio rebate menor a $33.000.

**¿Se arregla solo?**
Sí, hay un proceso automático que desactiva el envío gratis; esta pantalla permite forzarlo manualmente si falló.
