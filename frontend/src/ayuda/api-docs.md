# API docs

Área: Gestión
Ruta: Gestión → API docs
Permiso: Pedile a un administrador el permiso para ver la documentación técnica (admin.ver_api_docs).

## Para qué sirve

Muestra la documentación técnica de la API (OpenAPI) con un explorador interactivo (Scalar), con el token de sesión pre-cargado.

## Cómo se usa

Arriba dice **API docs**. La página carga la documentación de la API y la muestra en un explorador interactivo. Se puede navegar por los endpoints, ver parámetros y respuestas, y probar llamadas.

Si falla la carga, muestra **No se pudo cargar la documentación de la API.**

## Filtros y columnas

Sin filtros ni columnas.

## Botones y acciones

Sin botones ni acciones (el explorador permite probar endpoints).

## Preguntas frecuentes

**¿Para qué sirve?**
Para consultar la documentación técnica de la API de la aplicación.

**¿Se necesita permiso especial?**
Sí, el permiso de administración para ver la documentación técnica.
