# Traza

Área: Consultas
Ruta: Consultas → Traza
Permiso: Pedile a un administrador acceso a Traza.

## Para qué sirve

Permite consultar el historial completo de un producto o de un cliente: movimientos, facturas, pedidos y RMAs. Se puede buscar por serial, venta de MercadoLibre, factura o datos del cliente.

## Cómo se usa

Arriba dice **Traza** y aclara que se consulta el historial por serial, venta ML, factura o cliente.

Elegí el modo de búsqueda entre **Serial**, **ML ID**, **Factura**, **# Cliente**, **DNI/CUIT** y **Usuario ML**. Ingresá el valor y usá **Buscar** (o Enter). Mientras busca dice **Buscando...**. **Limpiar** borra los campos y el resultado.

En modo Factura, elegí el tipo (A/B/C/E/M/X), el punto de venta y el número de documento.

Los resultados se muestran en el visor de traza; para clientes hay paginación.

## Filtros y columnas

Sin filtros. Modos de búsqueda: Serial, ML ID, Factura, # Cliente, DNI/CUIT, Usuario ML.

## Botones y acciones

- **Buscar**: ejecuta la búsqueda.
- **Limpiar**: borra campos y resultado.

## Preguntas frecuentes

**¿Qué puedo consultar por serial?**
El historial completo del producto con ese número de serie.

**¿Qué puedo consultar por cliente?**
Las ventas, facturas y pedidos asociados a ese cliente (por número, DNI/CUIT o usuario ML).

**¿Qué puedo consultar por ML ID?**
La venta de MercadoLibre por su número de venta, de compra (paquete) o de envío, con sus productos, que salen de las ventas guardadas en **Ventas ML**. Cada pedido muestra su número del ERP (#...); si el ERP todavía no tiene pedido para esa venta, aparece como **Venta ML #** seguido del número de venta.
