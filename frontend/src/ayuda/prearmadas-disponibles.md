# Prearmadas disponibles

Área: Productos
Ruta: Productos → Prearmadas disponibles
Permiso: Pedile a un administrador acceso a las prearmadas disponibles.

## Para qué sirve

Muestra las prearmadas (combos armados) disponibles, agrupadas por SKU, con la cantidad de unidades listas y los SKUs que cubre cada modelo.

## Cómo se usa

Arriba ves el título **Prearmadas disponibles** y el total de unidades y modelos. Debajo está el buscador **Buscar por SKU, marca o descripción...** y el selector de variante Windows (**Todas las variantes**, **Windows Home**, **Windows Pro**, **Sin Windows**).

Los resultados se muestran en tarjetas. Cada tarjeta muestra el SKU, la descripción, la cantidad de unidades, la variante Windows (Home/Pro/Sin Windows), memoria y disco, y los SKUs que cubre. Podés expandir con **Ver las N unidades** para ver el código y la fecha de cada unidad.

Si no hay resultados dice **No hay prearmadas armadas con los filtros actuales.** Si falla la carga aparece **Error al cargar las prearmadas. Intentá de nuevo.** con **Reintentar**.

Abajo hay paginación con **← Anterior** y **Siguiente →** (200 por página).

## Filtros y columnas

Filtro por texto y por variante Windows. Sin columnas (vista en tarjetas).

## Botones y acciones

- **← Anterior** / **Siguiente →**: cambian de página.
- **Reintentar**: recarga si falló.
- Expandir/ocultar unidades de cada tarjeta.

## Preguntas frecuentes

**¿Qué significa "Cubre N SKUs"?**
Son los productos (SKUs) que esa prearmada puede satisfacer, algunos con upgrade.

**¿Cómo veo las unidades individuales?**
Tocá **Ver las N unidades** en la tarjeta.
