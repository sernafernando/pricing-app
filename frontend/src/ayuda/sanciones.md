# Sanciones

Área: RRHH
Ruta: RRHH → Sanciones
Permiso: Pedile a un administrador acceso a RRHH (rrhh.ver).

## Para qué sirve

Gestiona las sanciones aplicadas al personal: crearlas, verlas, anularlas y generar documentos.

## Cómo se usa

Arriba dice **Sanciones**. Si tenés permiso de gestión, el botón **Nueva Sanción** abre el formulario para crear una sanción (elegir empleado, tipo, fechas y motivo). El botón de configuración (⚙️) abre la configuración de tipos de sanción (si tenés permiso de configuración).

Los filtros son: empleado, tipo de sanción, fecha desde/hasta y mostrar anuladas. La tabla lista las sanciones con empleado, tipo, fecha y estado. Al tocar una sanción se abre el detalle; desde ahí se puede anular (con motivo) o generar el documento PDF.

## Filtros y columnas

Filtros: empleado, tipo de sanción, fecha desde/hasta, mostrar anuladas.

Columnas: empleado, tipo, fecha, estado.

## Botones y acciones

- **Nueva Sanción**: crea una sanción (si tenés permiso de gestión).
- **⚙️ Configuración**: configura tipos de sanción (si tenés permiso de configuración).
- Anular: anula una sanción (con motivo).
- Generar documento: descarga el PDF de la sanción.

## Preguntas frecuentes

**¿Quién puede crear sanciones?**
Quien tenga el permiso de gestión de RRHH.

**¿Se pueden anular sanciones?**
Sí, con un motivo.
