# Ejemplos de Corrección

Área: Tickets
Ruta: Tickets → Ejemplos de Corrección
Permiso: Pedile a un administrador acceso a los ejemplos de corrección (tickets.triage.ejemplos).

## Para qué sirve

Gestiona los ejemplos de corrección usados para entrenar el triage de tickets: muestra el texto original, el valor asignado por la IA y el valor corregido por un humano, con posibilidad de activar/desactivar cada ejemplo.

## Cómo se usa

Arriba dice **Ejemplos de Corrección** con un filtro por campo (Severidad/Urgencia). La lista muestra cada ejemplo con el texto, el valor IA tachado, una flecha y el valor corregido por humano (con color según el valor). También muestra la fecha de creación.

Cada ejemplo tiene un interruptor para activar o desactivar. Si no hay ejemplos, muestra un mensaje vacío.

La lista está limitada a 200 registros.

## Filtros y columnas

Filtro: campo (Severidad/Urgencia).

Sin columnas (vista en tarjetas/filas).

## Botones y acciones

- Interruptor: activa o desactiva un ejemplo.

## Preguntas frecuentes

**¿Qué es un ejemplo de corrección?**
Un caso donde la IA asignó un valor (severidad/urgencia) y un humano lo corrigió; sirve para entrenar el triage.

**¿Para qué sirven los colores?**
Indican el nivel del valor corregido (crítica/inmediata = rojo, mayor/alta = naranja, trivial/baja = gris, otros = azul).
