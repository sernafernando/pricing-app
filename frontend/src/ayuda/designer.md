# Designer

Área: Documentos
Ruta: Documentos → Designer
Permiso: Pedile a un administrador el permiso para diseñar documentos (documentos.disenar).

## Para qué sirve

Diseña plantillas de documentos PDF con un editor visual (WYSIWYG), eligiendo el contexto (ventas, RRHH, etc.) y las variables disponibles.

## Cómo se usa

Arriba dice **Designer**. Se elige un contexto (ventas, RRHH, etc.) y se cargan las plantillas y variables disponibles. Se puede crear una plantilla nueva, editarla en el editor visual, guardarla o eliminarla.

El editor permite arrastrar y soltar elementos, definir variables y previsualizar el documento.

## Filtros y columnas

Sin filtros. Selector de contexto.

## Botones y acciones

- **Nuevo**: crea una plantilla.
- **Guardar**: guarda la plantilla.
- **Eliminar**: borra la plantilla (con confirmación).

## Preguntas frecuentes

**¿Qué contextos hay?**
Los definidos por el backend (ventas, RRHH, etc.).

**¿Qué variables puedo usar?**
Las que corresponden al contexto seleccionado.
