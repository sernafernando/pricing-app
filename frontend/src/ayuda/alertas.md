# Alertas

Área: Gestión
Ruta: Gestión → Alertas
Permiso: Pedile a un administrador el permiso para gestionar alertas (alertas.gestionar).

## Para qué sirve

Gestiona las alertas del sistema: crearlas, editarlas, desactivarlas y configurar cuántas se muestran a la vez.

## Cómo se usa

Arriba dice **Gestión de Alertas**. Si tenés permiso de gestión, se listan las alertas con filtro por activas/inactivas/todas. Se puede crear una alerta (**Nueva Alerta**) o editar una existente. El estado se cambia con el botón Activa/Inactiva; el botón ✕ desactiva con confirmación.

Si tenés permiso de configuración, se puede configurar el máximo de alertas visibles y guardar.

## Filtros y columnas

Filtro: activas/inactivas/todas.

Columnas: Estado, Título, Variant, Vigencia, Prioridad, Comportamiento, Destinatarios y Acciones.

## Botones y acciones

- **Nueva Alerta**: crea una alerta.
- **Editar**: modifica una alerta.
- **Activa/Inactiva**: activa o desactiva una alerta sin confirmación.
- **Eliminar (✕)**: desactiva una alerta con confirmación.
- **Guardar** (en Configuración Global): guarda el máximo de alertas visibles.

## Preguntas frecuentes

**¿Quién puede gestionar alertas?**
Quien tenga el permiso alertas.gestionar.

**¿Se puede configurar cuántas alertas se muestran?**
Sí, si tenés el permiso alertas.configurar.
